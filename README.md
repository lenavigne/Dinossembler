# Dinossembler - Manuel

1) Manuel du jeu
Vous incarnez un petit poulet dont l'objectif est de trouver les morceaux de squelettes de dinosaures, répartis dans un musée, et de les ramener à leurs places.
Attrapez l'os, vidé avec le pointeur au centre, en maintenant le clic gauche de la souris. 
Lorsque vous relachez l'os et pointez sur sa supposée position sur le squelette rouge, l'os se déplace à la position pointée. Dans le cas, où vous ne pointez rien l'os retombe par terre, de même si la position choisie n'est pas celle de l'os relâché. 
Au fur et à mesure du jeu, et après chaque squelette assemblé avec succès, vous gagnez une capacité :
    1- saut (espace)
    2- course et brisage de vitres (maintien shift)
    3- vol plané (maintien espace)

Pour gagner, il faut assembler les quatres squelettes en s'aidant des capacités déverouillées, dans le temps imparti.
Pour perdre, il faut ne pas réussir à assembler les squelettes dans le temps imparti.
